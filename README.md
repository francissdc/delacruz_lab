## Getting Started

This project is a starting point for a Flutter application.

A few resources to get you started if this is your first Flutter project:

In this laboratory activity, I set up the Flutter development environment and created a new Flutter project in Visual Studio Code. Through this hands-on exercise, I became familiar with the basic project structure of a Flutter application, particularly the `lib/main.dart` file, which serves as the main entry point of the app, as well as the `README.md` file for project documentation.

Additionally, I learned how to initialize a local Git repository, stage and commit project changes, and push the files to a remote GitHub repository using terminal commands (`git init`, `git add`, `git commit`, `git remote add`, and `git push`). This workflow is essential for tracking code versions and collaborating on mobile programming projects.
